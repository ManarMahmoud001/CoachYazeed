# Yazeed Flifel — Performance Coaching Homepage

Production-oriented responsive React/Vite homepage using Tailwind CSS and Cairo typography.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Brand assets

The visual elements in `public/brand/` were cropped from the supplied Brand Identity Guide:
- circular checkmark
- directional arrow
- dashed line
- neon brush stroke
- dark honeycomb texture
- dark scratched/energy texture

Replace the intentionally neutral hero image placeholder with approved coach photography when it becomes available. No invented photography is included.
